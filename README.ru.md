# OBS AIMP Source (`obs-aimp-source`)

[English](README.md) • [Русский](README.ru.md)

[![OBS Studio](https://img.shields.io/badge/OBS%20Studio-33.0%2B-black.svg?logo=obsstudio)](https://obsproject.com/)
[![AIMP](https://img.shields.io/badge/AIMP-v4%20%7C%20v5-orange.svg)](https://www.aimp.ru/)
[![License](https://img.shields.io/badge/License-GPL%20v2.0-green.svg)](https://www.gnu.org/licenses/gpl-2.0.html)

Высокопроизводительный нативный плагин для **OBS Studio 33.0+**, обеспечивающий глубокую интеграцию с аудиоплеером **AIMP**: прямой захват звука процесса, изолированный аудиомониторинг, настраиваемый оверлей с внешней системой JSON-тем и интерактивную панель управления на Qt6.

Построен на базе современного официального шаблона плагинов **obs-plugintemplate** с поддержкой CMake Presets.

---

## 🚀 Основные возможности

### 1. Прямой захват звука (WASAPI Process Loopback)
- **Захват напрямую из `AIMP.exe`**: Перехват звукового потока на уровне аудиосессии через Windows Audio Session API (WASAPI Process Loopback). Больше не требуются виртуальные аудиокабели (VB-Cable, VoiceMeeter) или захват всего рабочего стола.
- **Студийное качество звука**: Захват в формате IEEE 32-bit Float с автоматической адаптацией частоты дискретизации (44.1 / 48 кГц, стерео и многоканальные конфигурации).
- **Сверхнизкая задержка**: Аппаратный кольцевой буфер (~50 мс) без рассинхронизации и с минимальной нагрузкой на процессор.
- **Бесшовное переподключение**: Автоматическое обнаружение запуска, закрытия и перезапуска AIMP с мгновенным подхватом аудиопотока.

### 2. Оверлей текущего трека (GPU-рендеринг)
- **Аппаратное ускорение**: Отрисовка плашки трека внутри графического пайплайна OBS (`gs_texture`, Premultiplied Alpha, кастомный блендинг).
- **Обложка альбома**: Мгновенное получение обложки через Win32 `WM_COPYDATA` со скруглением углов. При отсутствии обложки отображается стилизованная векторная нота-заглушка.
- **Плавная бегущая строка**: Автоматическая прокрутка длинных названий треков и исполнителей с настраиваемой скоростью (пикс/сек).
- **Индикатор прогресса и тайминги**: Скруглённый градиентный прогресс-бар с индикатором времени (`01:23 / 03:45`).
- **Автоскрытие при остановке и паузе**: Плавное затухание (~250 мс fade) при остановке или паузе воспроизведения.
- **Внешняя система тем**: Темы загружаются динамически из каталога `data/themes/` через файлы `manifest.json`. В комплекте 4 готовые темы:
  - 🌟 `default` (*Тёмное стекло / Default Dark Glass*) — современный тёмный глассморфизм с фирменным оранжевым акцентом AIMP (520×130).
  - ⚡ `neon` (*Неоновый киберпанк / Neon Cyberpunk*) — неоновое двухцветное свечение (Cyan & Magenta, 520×130).
  - 💊 `compact` (*Компактный виджет / Streamer Compact Pill*) — горизонтальная капсула (440×72) с безопасными отступами и защитой от наложения текста.
  - 💎 `card` (*Премиальная карточка / Emerald Luxury Card*) — карточка с изумрудными акцентами (520×130).
- **Кастомизация в свойствах источника**:
  - Полное переопределение цветов (фон, рамка, название, артист, тайминги, прогресс-бар).
  - Настройка семейств шрифтов и размеров для каждого текстового элемента.

### 3. Интерактивная док-панель управления (Qt6)
- **Мониторинг статуса**: Индикатор подключения (*Подключено*, *AIMP не запущен*, *Воспроизведение*, *Пауза*, *Остановлено*).
- **Быстрый запуск**: Кнопка «Запустить AIMP» с фирменной монохромной эмблемой появляется автоматически при закрытом плеере (путь к плееру находится через реестр Windows).
- **Тематические иконки управления**: Иконки кнопок (`Предыдущий`, `Воспроизведение / Пауза`, `Стоп`, `Следующий`, `Случайный порядок`, `Повтор`, `Громкость`, `Mute`, `Наушники`) динамически адаптируют свой оттенок под активную тему оформления интерфейса OBS Studio.
- **Интерактивный прогресс-бар**: Клик или перетаскивание ползунка для перемотки в любую позицию трека.
- **Кнопки управления**: `Предыдущий`, `Воспроизведение / Пауза`, `Стоп`, `Следующий`, `Случайный порядок` и `Повтор трека`.
- **Громкость плеера**: Регулировка внутренней громкости AIMP (0–100%) и кнопка отключения звука (Mute).
- **Громкость источника в OBS**: Логарифмический фейдер в децибелах (**дБ**, от -inf дБ до 0.0 дБ) для управления громкостью источника OBS.
- **Управление мониторингом**: Быстрое включение прослушивания в наушниках, интеграция в микшер и отдельный слайдер громкости мониторинга в дБ.
- **Встраивание в OBS**: Док-панель автоматически регистрируется в главном меню OBS: *Док-панели* → *Управление плеером AIMP*.

### 4. Изолированный аудиомониторинг и интеграция в микшер
- **Раздельный мониторинг**: Стример может слушать музыку в наушниках без вывода в эфир/запись, либо настраивать баланс громкости персонально для себя независимо от трансляции.
- **Отдельный источник-компаньон в микшере**: При включении опции *«Добавить мониторинг в аудиомикшер»* в микшере OBS появляется отдельный регулятор с фейдером и шкалой уровней (Volume Meter).
- **Умное контекстное меню**: Вызов «Свойств» или «Фильтров» у источника мониторинга в микшере автоматически открывает настройки основного источника AIMP.
- **Устойчивость к переключениям**: Корректная синхронизация состояния при переключении коллекций сцен, смене профилей и переименовании источников.
- **Обход UIPI**: Защита окон сообщений Win32 от изоляции привилегий интерфейса (`ChangeWindowMessageFilterEx`) — связь с AIMP работает даже при запуске OBS от имени администратора.

### 5. Полная локализация (i18n)
- 100% строк интерфейса локализованы:
  - `ru-RU.ini`: Русская локализация
  - `en-US.ini`: Английская локализация
- Полная синхронизация ключей и поддержка мультиязычных названий тем через `locale.json` или `Theme.<id>`.

## 📖 Руководство пользователя (OBS Studio)

### 1. Добавление источника на сцену:
1. В OBS Studio в блоке **Источники** нажмите кнопку **+**.
2. Выберите **Источник AIMP** (*AIMP Source*).
3. В окне свойств:
   - **Отображение**: Выберите тему оверлея, включите автоскрытие при остановке/паузе и настройте скорость бегущей строки.
   - **Звук**: Включите **Захват звука** для вывода музыки на стрим/запись. Включите **Мониторинг**, чтобы слышать музыку в наушниках, и задайте комфортную громкость.
   - **Цвета и шрифты**: При необходимости переопределите любые цвета и шрифты поверх выбранной темы.

### 2. Использование док-панели:
1. В верхнем меню OBS перейдите в **Док-панели** → выберите **Управление плеером AIMP**.
2. Закрепите панель в удобном месте интерфейса OBS (рядом с микшером, сценами или предпросмотром).
3. В док-панели доступны:
   - Обложка альбома, название композиции и исполнитель.
   - Интерактивная шкала времени с перемоткой.
   - Кнопки переключения треков, воспроизведения, случайного порядка и повтора.
   - Ползунок внутренней громкости AIMP.
   - Фейдер источника OBS и фейдер громкости мониторинга в дБ.

## 🛠️ Сборка и установка

### Системные требования:
- **ОС**: Windows 10 / 11 (64-бит)
- **Компилятор**: Visual Studio 2022 или 2026 (MSVC v143+) с поддержкой C++17
- **Система сборки**: CMake 3.28+ и Ninja
- **Фреймворк**: Qt 6.5+ (компоненты `Core`, `Gui`, `Widgets`)
- **OBS Studio**: Версия 33.0 или новее

### Быстрая сборка (локально):
Запустите скрипт сборки из корня проекта:
```powershell
# Сборка через Ninja (по умолчанию, каталог build/):
.\build.ps1

# Сборка через Visual Studio MSBuild (каталог build_vs/):
.\build.ps1 -Generator VS
```
Скрипт автоматически:
1. Определит и инициализирует среду сборки Visual Studio x64 (`vcvars64.bat`).
2. Сконфигурирует проект через CMake (Ninja в `build/` или Visual Studio в `build_vs/`).
3. Скомпилирует плагин с помощью Ninja или MSBuild.

Либо сборка напрямую через CMake Presets:
```powershell
# Сборка через Ninja:
cmake --preset windows-x64
cmake --build --preset windows-x64

# Генерация и сборка решения Visual Studio 2026 / MSBuild:
cmake --preset windows-vs
cmake --build --preset windows-vs
```

### Установка в OBS Studio:
Выполните:
```powershell
.\install.ps1
```
Скомпилированный плагин `obs-aimp-source.dll`, отладочные символы `.pdb`, файлы локализации и темы оформления будут скопированы в:
`%OBS_DIR%\plugins\obs-aimp-source\`

*(Если OBS Studio запущена в момент установки, скрипт безопасно обновит DLL без ошибок блокировки файлов).*

## 🎨 Создание пользовательской темы

Темы не требуют перекомпиляции плагина. Достаточно создать новую папку `data/themes/<theme_id>/` и добавить в неё файл `manifest.json`:

```json
{
  "id": "my_custom_theme",
  "name": "My Custom Theme",
  "author": "Streamer",
  "version": "1.0.0",
  "description": "Моя пользовательская тема оверлея",
  "layout": {
    "width": 520,
    "height": 130,
    "cornerRadius": 16,
    "padding": 14,
    "paddingRight": 14,
    "coverSize": 102,
    "coverRadius": 10,
    "coverSpacing": 16,
    "progressBarHeight": 6,
    "progressBarRadius": 3,
    "progressBarBottomOffset": 14
  },
  "fonts": {
    "titleFont": "Segoe UI",
    "titleSize": 15,
    "titleWeight": 700,
    "artistFont": "Segoe UI",
    "artistSize": 12,
    "artistWeight": 500,
    "timeFont": "Consolas",
    "timeSize": 11,
    "timeWeight": 400
  },
  "colors": {
    "background": "#1A1B24E6",
    "border": "#3A3D5480",
    "borderWidth": 1.5,
    "titleText": "#FFFFFF",
    "artistText": "#A2A7BD",
    "timeText": "#8E93AB",
    "progressBackground": "#282B3C80",
    "progressFill": "#FF7A00",
    "progressFillEnd": "#FFA44D",
    "glowColor": "#FF7A0040"
  },
  "assets": {
    "placeholderCover": "placeholder.png"
  }
}
```

> [!NOTE]
> Все размеры указываются в пикселях. Поле `paddingRight` опционально: если оно не задано, используется значение `padding`, а для тем-пилюль с большими радиусами скругления движок автоматически рассчитывает безопасный правый отступ для предотвращения обрезки текста.

### Локализация темы (`locale.json`)

Чтобы название и описание темы отображались на языке пользователя OBS Studio, создайте файл `locale.json` внутри каталога темы:

```json
{
  "ru-RU": {
    "name": "Моя пользовательская тема",
    "description": "Описание темы на русском языке"
  },
  "en-US": {
    "name": "My Custom Theme",
    "description": "Custom theme description in English"
  }
}
```

Плагин автоматически определит текущий язык интерфейса OBS Studio и отобразит локализованное название темы в выпадающем списке!
